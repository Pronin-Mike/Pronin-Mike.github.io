    Импорт

    Заполнить холодильник и добавить блюда из CSV, восстановить базу из JSON.

    Холодильник из CSV

    Колонки: name,amount,unit — по одной строке на продукт, например мука,1000,г. Единица измерения — только г, мл или шт. Строку заголовков можно не указывать, а разделителем может быть запятая, точка с запятой или табуляция. Дробное количество с запятой возьмите в кавычки: молоко,"1,5",мл.

    Блюда из CSV

    Колонки: title,section,ingredients,time,steps,notes. section — breakfast, snack, lunch или dinner. ingredients — через «;», каждый в формате название|количество|единица, например яйца|3|шт;сыр|50|г. steps — через «;».

    База из JSON

    Файл, полученный кнопкой «Экспорт JSON». Текущие блюда и холодильник будут заменены — подтверждение спросим отдельно.

    Настройки и бэкап

    Все данные живут в этом браузере. Бэкап — единственный способ их не потерять.

    Экспорт

    JSON подходит для полного бэкапа и переноса на другое устройство. CSV удобно открыть в таблице.

    Сброс данных

    Удалит все блюда и весь холодильник из этого браузера. Действие необратимо — сначала сделайте бэкап.

    Как это работает

    • Сайт полностью статический: ни сервера, ни внешних API — только файлы на GitHub Pages.
    • База хранится в localStorage браузера и не синхронизируется между устройствами: переносите её через экспорт/импорт JSON.
    • Ингредиент считается доступным, если название (без регистра и пробелов) и единица измерения совпадают точно, а количество не меньше нужного.
    • Пересчётов и синонимов нет: «1 ст.л.» и «200 мл» — разные единицы, продукт будет считаться отсутствующим.
    • Очистка данных браузера, режим инкогнито или другой браузер = пустая книга.
